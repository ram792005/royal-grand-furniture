# Royal Grand Furniture Atelier — Flagship Digital Showroom

A luxury digital showroom and 3D product catalog for **Royal Grand Furniture** (Nidadavole, Andhra Pradesh).

## Features
- **87 Curated Pieces**: Handcrafted Living Suites, Emperor King Cots, Dining Tables, Study Desks, and Storage Almirahs.
- **3D Interactive Studio**: Full 360° interactive 3D inspection powered by Google `<model-viewer>`.
- **Dual 3D Model Support**: Complete coverage with optimized `.glb` (Android & Web) and `.usdz` (Apple QuickLook AR for iOS).
- **Direct WhatsApp Commerce**: Instant quote and consultation lead generator with full product metadata.
- **Zero-Dependency Static Performance**: Instant load on global Edge CDN.

## Deployment
Deployed on Vercel with high-speed Edge CDN and automated SSL/HTTPS.
